# P3: ранний контракт арта для Builder

Автор: `asset-artist-r4d-p3-masks-01`. 28 октября 2026.
Это условия потребления арта, не новая спецификация заказа.
Состояние: ранний стык; самостоятельного визуального PASS ещё нет.

- Цельная неизменённая Jungle 1536×1536 остаётся единственным фоном.
- Координаты контуров: source pixels, origin top-left, +x right, +y down.
  Каждый polygon замкнут; alpha=1 внутри тела, 0 снаружи. Контуры не включают
  падающие тени. Растеризация с antialias в одном source-aligned масштабе.
- Перекрытие реализуется вычитанием alpha из шарика/тени либо восстановлением
  исходных пикселей через маску. Восстановление пикселей не создаёт отдельные
  перемещаемые препятствия: фон и геометрия остаются целыми и неизменными.
- `Art=false` полностью выключает и художественные маски. Geometry находится
  выше всех художественных перекрытий.
- Идентификаторы препятствий совпадают с exact P1 config. Native XY берутся
  только из него; матрицы из manifest остаются без ремапа.
- Pin occlusion: заднее положение определяется реальным native ball XY и
  опорой препятствия. Для боковых касаний предпочтительна передняя дуга
  footprint, а не сортировка всех объектов по screen-center. Ранняя версия
  имеет явный depth anchor и footprint; точный адаптер согласуется на первом
  реальном частичном перекрытии. Контуры и их координаты от seed/tick не зависят.
- Борты: отдельные области непрозрачного переднего тела без теней и без
  заливки игрового пола. Передние края корзин — отдельные области; задняя
  часть отверстия не становится непрозрачной заглушкой.
- Ball: отдельный RGBA PNG, straight alpha, без встроенной падающей тени.
  Объявляются canvas, alpha bounds, visible-circle center/radius и ground
  anchor. Радиус изображения масштабируется к native r16 через локальный
  горизонтальный масштаб принятой проекции; uniform sprite scale, без
  овального растяжения самого объёмного шара.
- Shadow: отдельный RGBA PNG, мягкий полупрозрачный тёплый тёмный отпечаток.
  Объявляются contact anchor, bounds, направление. На поле под шариком;
  учитывает те же foreground masks, не участвует в PRNG/физике.

Первый стык ограничен `flower-01`: контур цветка/основания и собственные
ball/shadow. До расширения комплекта нужен просмотр реального состояния
неизменённого sim-core с частичным перекрытием. Статическая монтажная проба
сама по себе не считается такой проверкой.
