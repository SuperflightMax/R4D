# P3: минимальный consumer contract для Artist

Предложение Builder, 28 октября 2026. Применяется внутри ORDER/P3, не меняет заказ.
Координаты масок — неизменённый `01-jungle.jpg`, 1536×1536. Цельный исходник
всегда остаётся основой. Маски возвращают его собственные пиксели поверх ball/shadow;
это не нарезка доски в переставляемые объекты и не восстановление пустого пола.

Файл `assets.json`, пути относительно него:

```json
{
  "schema": "r4d-p3-assets-v1",
  "sourceSize": [1536, 1536],
  "ball": {"path":"ball.png", "anchorPx":[256,256], "radiusPx":220},
  "shadow": {"path":"shadow.png", "anchorPx":[256,256], "radiusPx":220,
             "offsetRadius":[0.35,0.4], "scaleRadius":[1.15,0.42], "alpha":0.55},
  "occluders": [
    {"id":"leaf-01", "path":"masks/leaf-01.png", "rectPx":[0,0,1536,1536],
     "depthNativeY":33328.97811206313}
  ]
}
```

- PNG маски: белые RGB, прозрачный фон, alpha силуэта физического объекта;
  мягкая сглаженная граница допустима. Нарисованная падающая тень не является
  непрозрачным телом. Размер PNG должен совпадать с шириной/высотой `rectPx`.
  Прямоугольник может быть полным исходником или точным crop без rescale.
- `depthNativeY` берётся из принятого config для центра основания препятствия.
  Шарик за объектом при native `ball.y < depthNativeY`. Для наклонных бортов
  вместо скаляра допустимо `depthLineNative:[[x1,y1],[x2,y2]]`: глубина линейно
  интерполируется по native ball.x (с ограничением концами линии).
- Маска ограничивает видимые пиксели, глубина решает, когда они перекрывают
  шарик. Никаких условий по seed, времени или номеру тика. Основания/config
  не подгоняются. Сложный силуэт можно разделить на несколько source-aligned
  областей с отдельными основаниями и стабильными уникальными ID.
- Ball/shadow — собственные RGBA PNG. `anchorPx` — центр шарика/тени;
  `radiusPx` — радиус шарика в текстуре (без прозрачного padding), для тени —
  радиус исходной нормализованной текстуры. Масштаб берётся из r16 и проекции.
  `offsetRadius` — смещение тени в native радиусах по плоскости;
  `scaleRadius` — полуоси тени в радиусах. Alpha PNG и `alpha` перемножаются.
- Небольшой первый handoff: настоящий ball/shadow + одна маска leaf-01
  (или другой реально встречаемый объект), затем вся сцена, борта и корзины.
- Artist передаёт exact commit/path. Builder читает эти объекты, не правит
  Artist worktree. До готовности ассетов диагностика может показать контур,
  но он не считается художественным результатом.

Требуемые поправки контракта согласуются через Lead; собственная реализация
не получает права менять метод P3, исходник, mapping или ядро.
