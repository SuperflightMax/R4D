# Q5: сначала конструкция

Один персонаж на заранее подготовленной конструкции: [контракт](CONSTRUCTION.md), [фиксация до генерации](CONSTRUCTION_FREEZE.md), [изменения вслед за генерацией](CONSTRUCTION_CHANGES.md). Технические маски не являются финальным артом. Происхождение общего spring/IK/UI — Q2 (первоначально Q1); новая конструкция и художественный комплект отдельные.

Запуск из этой папки: `npm ci`, `npm run dev`. Адрес `http://127.0.0.1:4185/`, strictPort; сборка `npm run build`, самопроверка `npm test`. Статическая публикация поддерживается относительным base; её выполняет назначенный релизный маршрут после CTO.

Кнопки покой/низкая поза/идти/прыжок принимают команды в любой момент. 1/2/3, A/D, стрелки, пробел; P — пауза, точка — кадр, B — оси, R — сначала. Можно менять наземную цель в воздухе. Четыре маршрута используют те же команды общего механизма. Кнопка «Конструкция / арт» переключает техническую форму и художественные PNG на тех же осях; «Исходная поза» показывает нулевые локальные углы, а не одно из требуемых состояний. Фоны и замедление помогают осмотру.

`construction/v1/rig.json` определяет физическую сборку и слои. Manifest Artist поставляет пути художественных текстур. PNG ожидаются на согласованных 256×256 холстах без индивидуального масштабирования. Реальная непрозрачная подошва измеряется из alpha>=128; прозрачные поля не увеличивают видимый масштаб. Изменения конечного покрытия/силуэта раскрываются Artist в ASSET_PROCESS.

Один именованный кандидат q5-c1 после интеграции и самопроверки; после freeze изменения только по отдельному разрешению CTO. Независимые QA и художественная оценка смотрят ту же сборку; самопроверка не означает окончательную приёмку. Q1–Q4 не изменяются, Q6 не входит в работу.
