# Самопроверка Builder Q5

Один полный кандидат после ранней настоящей цепи torso/head и torso/arm. Предварительные схемы не выдавались за финальный арт. Construction v1 и19 hashes существовали до7 generation-вызовов; Artist/Lead подтвердили freeze. Artwork7→12 PNG, физические оси/длины/слои берутся прямо из v1. Размещение художественных пикселей потребовало явной uniform регистрации; before/after и фактическое отклонение подошвы раскрыты CONSTRUCTION_CHANGES, ASSET_PROCESS и assets/measurements.json.

`npm test`:4/4, проверены hashes v1, endpoint нового120+120 рига,9 origin/airborne-target jumps, сохранение pose/velocity при retarget и обе обычные/две прерванные последовательности. `npm run build` прошёл на полном комплекте.

Изолированный Chromium q5-builder через playwright-cli:9 jump starts/landings,4 маршрута,2 mid-transition; idle/low/move/jump prepare/flight/land, low root75.4 (около32% длины ноги), колено99°. Команды в полёте не телепортируют в наземную позу. Обычная команда не сбрасывает текущую pose; клавиатура, pause/frame step, bones, bind/выход по команде, construction/art, dark/light и390px без горизонтального overflow проверены. Обработчики служат реальным кнопкам; диагностический step продвигает тот же механизм. 37 наблюдений: browser-selfcheck-result.json. Кадры: output/playwright/builder/. Последний console: Errors0/Warnings0. Ранний служебный favicon404 устранён до кандидата; продуктовых JS ошибок не наблюдалось.

Визуально осмотрены idle/low/move/flight и ранние chains. Полный эмалевый механический образ узнаваем, low меняет суставы; накладки и внутренние тёмные линии заметны, особенно на локте/тазе/колене. Один растр Near/Far даёт ограниченную глубину. Head/forearm/foot отличаются от template (97.18/98.04/86.09% coverage); не закрашены ради метрики. При установившемся шаге ближайшая реальная подошва на2с наблюдения поднимается до1.84835 экранного px: smoothing подъёма стопы оставляет небольшой отрыв. Горизонтальное отсутствие sliding и физический баланс не гарантируются. Жёсткий профиль не выполняет поворота в глубину.

Это самопроверка реализации, не независимый PASS и не приёмка качества. После q5-c1 runtime/art/provenance неизменны; дальнейшие коррекции только CTO. Сервер4185 оставлен команде, скрытый Node/Vite PID114040, output/builder/vite.*. Чужие процессы/файлы и Q1–Q4 не менялись. Git централизует Lead.
