# Критерии независимого Visual QA Q6

Проверяется только q6-c1, один полный проход. Staff visual-qa-r4d-q6-01; заказчик CTO cto-r4d-01.

1. Сопоставимость: общий clock/pose, одинаковые camera/scale/pivots/layers. Source offset — отдельная диагностика, без ранжирования как художественного варианта.
2. Оформление J0/J1/J2: все пять целей, крайние и промежуточные положения, движение между ними. Оценить сквозные зазоры, торцы, двойные контуры, непрерывность ткани/силуэта, жёсткость, скачки и читаемость наколенника.
3. Получение M1/M2: тот же target J1; отдельно регистрация, обрезание, дрейф материала и силуэта. Сохранение исходника при compositing не приписывать генератору.
4. Видимость: target 0.42 и diagnostic 0.84, оба фона, desktop 1420×1000 и узкий viewport 390×844. На mobile учитывать CSS scale, не выдавать 0.42 за фактический экранный масштаб.
5. Взаимодействие: настоящие UI-команды, play/pause/step и смена цели во время перехода. Диагностическое продвижение того же Motion используется для точных кадров и отделяется от реального воспроизведения.
6. Результат: видимый дефект, предпочтение и гипотеза причины различаются. Лучший/худший оцениваются отдельно для J и M; существенные ограничения сохраняются даже при stop/show. Никаких исправлений, повторной генерации или второго полного прохода.
