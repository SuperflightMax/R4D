# Q3: фонарный краб

Отдельный опыт с радиальной трёхопорной конструкцией. Код управления/страница адаптированы из Q2; механизм ног и параметры Q3 новые, данные/арт Q1/Q2 не изменены. Изготовление и реальные привязки: ART_DIRECTION.md, ASSET_PROCESS.md, public/art/manifest.json. Полномочия: BRIEF.md.

Из D:\dev\R4D:

    npm --prefix experiments/q3-other-anatomy ci
    npm --prefix experiments/q3-other-anatomy run dev

Адрес http://127.0.0.1:4183/. strictPort: не запускать второй сервер, если порт уже занят командой. Для публикации npm --prefix experiments/q3-other-anatomy run build; dist использует относительный base. Тесты: npm --prefix experiments/q3-other-anatomy test.

1/2/3 выбирают покой/низкую позу/шаг. A/D и стрелки двигают при удержании. Пробел — прыжок, включая середину перехода; в полёте наземная команда меняет посадку. P — пауза, точка — кадр, B — кости, R — сначала. Кнопки дублируют команды. Четыре примера маршрутов подают те же команды; любой ручной запрос прекращает маршрут.

Низкая поза складывает три независимые цепи и раздвигает опоры. Шаг — сдвиг фаз1/3, перенос1/4 цикла, две опоры в установившемся ходе. IK сохраняет длины100/120 и горизонтальную опору; край настоящего PNG измеряется по alpha>=128. Дальняя плоскость на20px выше передней представляет глубину фиксированного ракурса. Это стилизованная кинематика без физики устойчивости, разворота ракурса или реалистичной симуляции.

Переходы используют общие цели и непрерывное состояние, без клипов на каждую пару. Во время прыжка общий подъём применяется к корпусу и ногам; поджим ограничен общим расстоянием до поверхности, чтобы не сохраняться после контакта. __R4D.snapshot() даёт фактические положения, решения цепей и экранные зазоры; __R4D.step(dt) использует тот же ход времени, что просмотр.

После CANDIDATE код/входы заморожены для единственного независимого прохода QA и просмотра художника. Самопроверка Builder не является независимой приёмкой. Дальнейшая коррекция только по отдельному разрешению CTO.
