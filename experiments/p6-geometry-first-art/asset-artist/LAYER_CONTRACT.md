## Доска после обязательной цельной пробы

1. whole-board raw: нетронутый output и его фактический размер/hash, отдельные first/best/failure.
2. floor/background RGBA или RGB: непрерывный пол и внешний мир без динамически
   перекрывающих частей; удалённые объекты не оставляют теней/ореолов/дыр.
3. obstacle visual layers: реальные графические силуэты с alpha, ID строго из config;
   декоративные части могут быть разбиты на несколько слоёв ради частичного перекрытия.
4. obstacle shadows: отдельный ground слой либо явно сохранённые baked shadows в floor;
   для каждого ID ровно один источник тени, без дублирования и старых следов.
5. boundary/receiver front и rear parts: alpha-слои для видимого прохождения шарика;
   четыре basket mouth соответствуют receiver IDs, rim не считается физическим collider.
6. metadata: source rect, anchor в source px, native base point/radius/ID из config,
   texture path/hash, порядок и маски, происхождение (whole edit / extraction / correction).

Сначала передаётся actual whole-image результат с registration check. Подготовка
слоёв не маскирует его дефекты. Последующий компонентный вариант маркируется отдельно.
Все prepared board-слои имеют общий full-frame 1536-square registration или явный
rect/anchor. Raw не перезаписывается. Если output иного квадратного размера, consumer
получает единственный full-frame uniform scale; crop и локальная деформация запрещены.

## Собственный ball

Отдельный прозрачный PNG: одна объёмная круглая бирюзовая каменная/глазурованная
сфера, мягкий блик сверху справа, без нарисованной падающей тени и без свечения.
Прозрачный padding. Metadata указывает фактический canvas, alpha bounds, center и
visible radius; consumer масштабирует по physical r=16 и локальному масштабу проекции,
а не задаёт постоянный экранный диаметр. Текстура остаётся круглой, не сплющивается
в эллипс пола. Никакого чужого ball/shadow и никакого технического круга вместо арта.

## Отдельная ball shadow

Прозрачный PNG мягкого полупрозрачного тёмно-зелёного/коричневого пятна без объекта,
читаемого на светлом полу в обычном масштабе. Центр/ground anchor и opacity задаются
metadata; простой ground shape проецируется той же принятой матрицей, с согласованным
смещением вниз-влево и мягкостью. Дополнительная динамическая световая модель не нужна.
Тень идёт на полу, перекрывается основаниями/бортами согласованно и не путешествует
над верхушками. Цвет/форма/opacity проверяются в сборке, не по наличию файла.

## Consumer проверяет в интеграции

Арт/геометрия независимы. Отключённый арт отключает и его невидимые маски.
Контур actual config выше арта. Сортировка по одному центру не объявляется достаточной:
до/контакт/после, боковые отскоки, частичный overlap, basket rim проверяются на реальных
тиках native sim-core. Неподтверждённые случаи и дефекты входа обозначаются явно.
