## Геометрия и схема слоёв

- 25 пинов: `flower-01…07` (розовые низкие объёмы), `leaf-01…05` (бирюзовые), `frog-01…05` (зелёные), `wood-01…08` (высокие охристые).
- 16 сегментов: `far`, `left-1…6`, `right-1…6`, `near-divider-1…3`.
- Один `board01-start`; четыре `receiver-01…04`.
- Порядок: окружение → пол → тени на полу → объёмы границ → объекты от дальних к ближним → корзины → диагностическое наложение по запросу. Для движения разделение тела объекта и перекрывающей передней части будет определяться по фактическому арту; один depth sort заранее достаточным не объявлен.
- `config.json`: 9503 bytes, SHA-256 `dd5c519cd6d4b7295118e0a3a1063efed424a0ce739450bd5153c6a9941982db`.
- `manifest.json`: 11565 bytes, SHA-256 `7784dc0a215d0e472cf06a4eee03793592727cf0fa9a1fa0e0c78e5f1d17da18`.
- В `geometry-draft.mjs` импортируется именно общий `inputs/projection.mjs`. Максимальная ошибка обратного преобразования контрольных точек: `1.0289757937229989e-11` native units.

## Ограничения

Принятые данные задают круги оснований и плоскую проекцию. Высота объёмов, их палитра, декоративные бортики и тени — явно заданные иллюстративные направляющие, а не восстановленная 3D-камера. Полигон пола сохраняет неровные границы принятого входа. Круги корзин показывают области native capture, а не полный видимый размер корзин; их можно художественно окружить корзиной, не сдвигая центр. Между полем и корзинами остаётся принятый промежуток. Верхний прямоугольник обозначает единственный старт; дополнительных физических стартов нет.

Нельзя подгонять коллайдеры/гомографию под удачную генерацию. Совпадение результата проверяется тем же overlay. Видимые высоты можно художественно уточнять при сохранении оснований, ракурса, расстановки, старта и корзин.

## Воспроизведение

Из назначенного E: checkout, с TEMP/TMP на own runtime:

```powershell
python experiments/p6-geometry-first-art/builder/scripts/import-inputs.py
node experiments/p6-geometry-first-art/builder/scripts/geometry-draft.mjs
python experiments/p6-geometry-first-art/builder/scripts/render-draft.py
```

Требуются Node.js, Python 3 и Pillow. Полный inventory и контрольные суммы находятся в `inputs/inventory.json` и `draft-v01/hashes.json`. Private native source здесь отсутствует. JPG не копируется в репозиторий.
