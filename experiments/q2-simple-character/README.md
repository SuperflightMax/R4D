# Q2 — новый простой персонаж

Текущий результат — `q2-c2`. [Итог для CTO](RESULTS.md): рекомендация `stop/show with limitations` после независимых проверок и личного просмотра художника. Таз улучшен частично; ступень в глубоком приседе, сегментированные суставы и небольшой зазор опоры остаются известными ограничениями. Полного художественного PASS нет. Сравнимый c1 сохранён в `assets/comparison/`.

Область и границы — в `BRIEF.md`, фактический ход — в `STATE.md`. Способ изготовления арта — в `ART_DIRECTION.md` и `ASSET_PROCESS.md`.

Из `experiments/q2-simple-character`:

```powershell
npm ci
npm run dev
```

Открыть `http://127.0.0.1:4182/`. `npm test` проверяет переходы механизма; `npm run build` собирает отдельный статический `dist/`. Настоящий комплект `public/art/manifest.json` и 12 PNG подключены по `ASSEMBLY_CONTRACT.md`. Названная собранная попытка и её точная версия — в `CANDIDATE.md`.

Покой / низкая поза / ходьба доступны кнопками и клавишами 1 / 2 / 3. Пробел запускает прыжок; A/D и стрелки задают удерживаемое направление. Наземную цель можно менять в воздухе. Пауза, шаг, замедление, разные фоны и кости помогают рассматривать результат. Четыре маршрута подают обычные команды тому же механизму; ручная команда прекращает маршрут.

Механизм: общие пружинные фильтры сохраняют текущую позу и скорость, ноги решаются IK к целям стоп. Единые фазы подготовки, полёта и контакта используют последнее выбранное наземное состояние. Координатные амплитуды зависят от длины ног нового персонажа; подошва измеряется по альфе настоящей PNG. Это адаптация кода Q1/baseline 6.1, без заимствования их персонажа. Отдельных клипов под пары состояний нет.

Числовые проверки не подтверждают художественное качество, чистоту соединений или естественность. Это нужно проверить на настоящем растре в движении с художником и независимыми QA. Текущее техническое ограничение: профильный двуногий комплект с двумя сегментами ног, без разворота в глубину, mesh и сменных ракурсов.
