# Q3C · материалы Stage D

Мотылёк v1 доступен для подключения. Его корпус из патины и тёмной эмали несёт две светлые створки с латунными нервюрами. Их плоскости остаются различимыми при размахе 54 мировые единицы, около 39 px при масштабе 0,72. Ориентиры по масштабу и фазам взяты с [листа Concept](../../design/concept-stage-d/MOTH_HUNT_SHEET.svg).

## Мотылёк

| Файл | Роль |
|---|---|
| `moth-body.svg` | `moth.body`, корпус 22 × 8 U с усиками. Начало координат в груди, передняя сторона вдоль +x |
| `moth-wing-left.svg` | `moth.wing.far`. Ось в (0,0), посадка на корпусе (−1, −2,5) |
| `moth-wing-right.svg` | `moth.wing.near`. Ось в (0,0), посадка на корпусе (−1, +2,5) |
| `MOTH_V1.json` | Имена, размеры, порядок слоёв, посадки, габарит и точки взмаха |

Пути текстур в JSON относительны к каталогу пакета. Для каждого спрайта использовать `spriteAnchor`, ширину и высоту `viewBox` в мировых единицах. Положение крыла равно его `parentAttachment` из корпуса. Дальнее крыло рисуется первым, ближнее следующим, корпус перекрывает оба основания. Файлы уже направлены по нужным знакам y. Каждому крылу нужен собственный поворот вокруг продольной оси. Для бокового вида применяется положительное проекционное `scale.y` вокруг его шарнира.

`flightProfile` даёт замкнутый цикл 205 мс. Фазовый сдвиг уже входит в выборки, а плавная интерполяция каждого отрезка сохраняет движение на стыке цикла. Радиус 37 в JSON подходит для предварительной проверки попадания всего силуэта в разрешённую зону при наклоне. Захват проверяется по эллипсу груди с центром (−2,0) и полуосями 11 и 4, преобразованному в мировые координаты. Этот контракт заменяет временный круг радиуса 7 в `hunt.js`. Мировая точка фактического контакта идёт в эффект. [Окончательные размеры Concept](../../design/concept-stage-d/MOTH_HUNT_HANDOFF.md).

## Удар

| Файл | Роль |
|---|---|
| `impact-brass-chip.svg` | Фасеточный латунный обломок |
| `impact-enamel-chip.svg` | Светлая эмаль крыла с металлическим краем |
| `impact-shaving.svg` | Загнутая стружка с латунным бликом |
| `impact-spark.svg` | Искра, острие вдоль +x |
| `impact-flash.svg` | Вспышка радиусом 5 U |
| `impact-dust.svg` | Полупрозрачная пыль радиусом до 22 U |
| `IMPACT_V1.json` | Текстуры, анкеры, количества, диапазоны хода и жизни |

После подтверждённого захвата один раз сохранить `contactWorldXY` и направление удара. Каждая группа эффекта получает это начало, включая пыль с задержкой 20 мс. Короткий акцент 35–60 мс следует точке контакта. Искры уходят вперёд, сколы и стружка вращаются в более широком секторе. Суммарный след держится в пределах 32 U. Seed задаёт выбор текстур, углов и скоростей для воспроизводимого прогона.

Все SVG автономны, рассчитаны на 4 px на мировую единицу и используют прозрачный фон. Имена частей и анкеры закреплены в двух JSON. Локальные листы просмотра находятся в игнорируемом `output/`.

Проверены девять SVG, пути, размеры и анкеры обоих JSON. На листе Chromium из этих SVG поверх кадра C2 при ширине 360 px читаются обе плоскости крыла и корпус. Расчётный размах 39,21 px. Образец удара сохраняет контур клешни. В живой сцене остаётся проверить появление в допустимой зоне, синхронизацию эффекта с захватом и повтор.
