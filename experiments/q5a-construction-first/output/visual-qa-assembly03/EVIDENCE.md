# Выдача Visual QA ASSEMBLY03

Отчёт: `../../VISUAL_QA_ASSEMBLY03.md`.

Предназначены для выдачи только файлы непосредственно в этой папке:

- `A-*`, `B-*`, `M-*` и `desktop-realtime.webm`, `mobile-realtime.webm`: реальные прогоны двух обязательных последовательностей.
- `C-*`, `P-*`, `transitions.json`, `mobile-transitions.json`: все направления наземных переходов, прерывания, start/stop, pause/step/slow.
- `J-*`, `jumps.json`: три исходных состояния полного прыжка и повторные команды в фазах.
- `R-*`, `details.json`: стопы/опора, махи, посадка, повтор jump.
- `W-*`, `regressions.json`: прежняя промежуточная ошибка ткани около frame186, recovery.
- `F-*`, `framing-desktop.json`, `framing-mobile.json`: перепроверка apex на двух фонах, обоих масштабах и с диагностикой.
- Полные UI/viewport PNG, `mobile-slow.json`, журналы команд/консоли, `capture-summary.json`, `environment.json`, `cleanup.json`, снимки Git-статуса.
- Собственные `*.js`, `*.py` и `cli*.json` позволяют понять и повторить способ получения этих материалов.

**Не включать в выдачу `service/**`, `service-mobile/**`, любые `.playwright-cli/**`.** Это временные браузерные snapshot/console-копии, а не принятые доказательства. Удаление двух собственных временных папок было отклонено автоматической проверкой (`blocked by policy`), поэтому они оставлены без обхода запрета. Browser sessions закрыты. Другие `.playwright-cli` проекта не изменялись и не входят в этот пакет.

Исходные PNG сохраняют браузерное изображение. Контактные листы — уменьшенная/частично обрезанная навигация и не заменяют исходники для оценки границ canvas. У desktop realtime A/B отсутствуют возвращённые CLI таблицы tick: сохранены видео, PNG и исполнявшиеся сценарии; точные ticks им не приписываются.
