## Проверки и просмотр

`prepare_attempt03.py --check` повторяет все 86 создаваемых файлов побайтно без записи. `validate_attempt03.py` независимо проверяет 15 ID, RGBA 1024×1024, точный ICC, alpha, pivots и SHA; 76 authored-hand coverage случаев (19 поз × 2 кисти × 2 масштаба), контрольные цветовые срезы запястий и ткани, 162 защищённых файла и геометрию. Результаты записаны в `validation.json` и `independent-checks.json`; фактическая повторяемость — в `reproduction.json`.

Геометрия: 0 инверсий, 0 строгих самопересечений; 28 предусмотренных нулевых fold-граней учитываются отдельно. Во всех 19 статических позах 0 внутренних дыр/выходов за контрольную оболочку; на 2× тело проверено отдельно от authored-контура кистей, сами кисти — независимым обратным переносом маски. Авторская альфа реально вычитает покрытие во всех 38 парах поза/кисть и не восстанавливается заливкой. Цветовые пробы дают max-channel delta 0 на запястьях и менее 1/255 на тканевых стыках; это локальные пробы, не доказательство идеальности всей живописи.

Полные листы всех 19 поз: `preview/light-sheet-1x.png`, `dark-sheet-1x.png`, `light-sheet-2x.png`, `dark-sheet-2x.png`. Целевой viewport 960×640; 2× — повторный рендер, не увеличение картинки. Для каждой позы сохранены RGBA и два фона 1×; для low_deep, jump_landing и range_compression — дополнительные крупные 2× виды. Просмотрены оба листа, bind, низкая поза и компрессия крупно. Кисти, внутренние тканевые полосы и свет сгибов улучшены; роботизации, дисков, брони или скрытых торцов суставов не добавлено.

Динамика, переходы и качество в движении здесь не проверялись и не запускались. Concept/Builder должны оценить финальную выразительность кистей, объём сильных сгибов и остаточные внутренние границы ткани. Числовой PASS не закрывает AR1–AR3 вместо их независимого просмотра. Приёмку и дальнейшую production assembly решает CTO.

## Воспроизведение

Из `D:\dev\R4D`, Python 3.10.6, Pillow 12.1.1, numpy 2.2.6, без установки зависимостей:

```powershell
python -B experiments/q5a-construction-first/art/attempts/03/prepare_attempt03.py --check
python -B experiments/q5a-construction-first/art/attempts/03/validate_attempt03.py
```

Без `--check` первая команда перезаписывает только созданные результаты attempt03; для просмотра готового пакета она не нужна. `candidate-package.json` / `candidate-validation.json` — выдача текущего кандидата; root `art/package.json` / `art/validation.json` повторяют их побайтно. Сгенерированные локальные `package.json` / `validation.json` остаются отдельными результатами воспроизведения и не содержат самоссылочных хешей.

Для интеграции Builder: читать `file` и `silhouette_alpha_file` относительно `art/`; PNG — straight alpha. RGB передаётся через `integration_v4.material_rgb`, а две маски `L` — отдельно в `render(..., silhouette_alpha={surface_id: numpy.asarray(mask)})`. `load_materials()` сам по себе не подставляет эти authored-маски. Только непрозрачная v4-геометрия или RGB без отдельного `silhouette_alpha` восстановят срезанные кончики и не воспроизведут выбранный кандидат. Сохранённые preview демонстрируют именно вызов с обеими масками; статический рецепт — `prepare_attempt03.build()`.
