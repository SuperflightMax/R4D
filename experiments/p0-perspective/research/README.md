# P0 perspective — research v0.1

Этот каталог — передача Researcher для первого прохода P0. Он не является
готовой доской и не заявляет точное восстановление камеры исходного рисунка.

## Что брать в работу

- [`perspective-model-v0.1.md`](perspective-model-v0.1.md) — основания выбора,
  формулы, признаки сходства, допуски и ограничения.
- [`perspective-model-v0.1.json`](perspective-model-v0.1.json) — те же опорные
  числа в машиночитаемом виде для Builder и проверок.
- [`perspective-template-v0.1.svg`](perspective-template-v0.1.svg) — квадратный
  технический шаблон плоскости, рядов глубины и согласованных объёмных образцов
  для Concept Artist и как control/reference image генератору.
- [`CROSS_SERIES_CONCLUSION_AND_RECIPE.md`](CROSS_SERIES_CONCLUSION_AND_RECIPE.md)
  — вывод по проверенной серии F1–F4 и воспроизводимый layered-рецепт с точными
  источниками, ограничениями и границей результата.

Исходный референс остаётся только для чтения:
`K:\Agents\R4D\Assets\perspective\03-sun-temple.jpg`.

## Как применять

1. Concept Artist использует исходный JPG как художественный ориентир, а SVG —
   только как геометрическую опору. Сетка и подписи не входят в готовый арт.
2. Builder строит оверлей и проверку по JSON, не подгоняя параметры отдельно к
   каждому кандидату.
3. Visual QA сравнивает все новые доски по одному вектору метрик из Markdown.
   Числа отсекают явный уход ракурса, но не заменяют просмотр объёма и
   художественной читаемости.

Если генератор не принимает SVG, его можно растеризовать в 1536 × 1536 без
неравномерного масштаба и обрезки. Сам референс в Git не копировать.
