# P0 contract v2 — deterministic layered composition

Статус: согласованный машинный контракт **до новых изображений**. Он не
открывает сборку L1 и не разрешает финальную серию. Asset-компоненты ещё не
подставлены; этот пакет не создаёт для них заглушки и не рисует новый арт.

Канонический машинный результат:
[`generated/composition-contract-v2.json`](generated/composition-contract-v2.json).
Он строится из Research v0.1 и фиксированных решений CTO командой:

```powershell
npm run build:contract:v2
npm run check:contract:v2
```

Общие команды `npm run build` и `npm run check` включают как прежний Builder
v1, так и этот контракт.

## Зафиксировано

- окончательный кадр: **1536 × 1536 RGBA**;
- playable quad в нормированных и точных дробных pixel-координатах;
- дальний и ближний seams: `q=0.255` / `391.68 px` и `q=0.775` /
  `1190.40 px`;
- base-center anchors: `q=.338/.453/.567/.681`, то есть
  `519.168/695.808/870.912/1046.016 px`;
- один и тот же RGBA master для всех четырёх повторов;
- равномерные масштабы `0.939/0.978/1.018/1.058` одновременно по X и Y;
- стабильная back-to-front сортировка по `(q, p, instanceId)`;
- contact shadow каждого экземпляра использует тот же base-center anchor и тот
  же uniform scale, рисуется непосредственно перед своим master;
- control markers, сетки, оси, подписи, debug-точки и цветные зоны запрещены в
  L1/final output.

Горизонтальный `p` каждого экземпляра сейчас намеренно не изобретён: его
зафиксирует L1 composition только после получения реальных Asset components.
После фиксации он не может зависеть от запуска, seed или ручной подгонки.

Все допуски скопированы из Research JSON побайтно по значениям. Проверка падает,
если список anchors/scales, quad, seams, порядок слоёв или любой допуск
изменён/ослаблен.
