# P0 Asset Artist — diagnostic d1

Одна диагностическая генерация после gate Lead. Это checkpoint перед серией из
четырёх законченных досок, а не начало финальной серии.

## Состав

- `INPUTS.md` — фактические изображения, роли, hashes и exact commits базы;
- `inputs/formal-reference-v1.png` — растровая передача единственного
  геометрического control;
- `prompts/d1-prompt.txt` — дословный запрос встроенному генератору;
- `output/d1-jade-sky-observatory.png` — неизменённый результат первой и
  единственной генерации d1;
- `RUN_RECORD.md` — фактический способ запуска и доступные настройки;
- `SELF_CHECK.md` — авторская проверка результата без подмены независимого QA.

Четыре финальные доски до решения Lead после checkpoint не запускались.
