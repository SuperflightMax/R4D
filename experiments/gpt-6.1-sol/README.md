# «На ходу» — R4D / GPT-6.1 Sol

Независимый браузерный PoC: художественный персонаж из 13 прозрачных PNG,
иерархический скелет, стойка, ходьба и прыжок с подготовкой и приземлением.
Исходные изображения, нарезка и история их подготовки — в `assets/` и
`ASSET_PROCESS.md`. Отдельный цельный рисунок в исполнении не используется.

## Запуск

Node.js 20.19+ или 22.12+; проверено с Node 24.15.0 и npm 11.12.1.
В PowerShell из `D:\dev\R4D\experiments\gpt-6.1-sol`:

```powershell
npm ci
npm test
npm run build
npm run preview
```

Открыть http://127.0.0.1:4176/. Порт фиксирован; при занятом порте сервер
сообщает ошибку. Для разработки — `npm run dev`. `dist/` содержит готовую
production-сборку и ассеты, её можно раздавать любым статическим HTTP-сервером.
Открытие HTML через `file://` не поддерживается.

## Управление

- Удерживать D / →: движение вправо, A / ←: влево; отпустить: остановка.
- Кнопка «Идти» фиксирует движение без удержания клавиши.
- Пробел или «Прыгнуть»: прыжок из стойки или ходьбы. Ввод движения можно
  менять в воздухе; после приземления используется актуальный ввод.
- P: пауза; точка или «Шаг»: пауза и ровно 1/60 секунды вперёд.
- B: кости и суставы; R: сброс.
- Под «Диагностика и воспроизведение»: замедление и воспроизводимый сценарий
  двух прыжков со сменой ввода в воздухе. Во время сценария ручной ввод
  движения/прыжка возвращает управление пользователю.

## Что устроено внутри

`assets/manifest.json` задаёт прозрачную деталь, родительскую кость, точку
поворота в PNG, смещение сустава относительно родителя и независимый слой.
Положение каждой детали вычисляется по иерархии; порядок отрисовки отдельный,
чтобы дальние руки и ноги оставались за телом. Canvas содержит настоящие
PixiJS Sprite, загруженные из `parts/*.png`.

`src/motion.js` задаёт целевые позы и физику прыжка. Стойка дышит, ходьба
зациклена; двухзвенная обратная кинематика удерживает подошвы на земле и
поднимает переносимую стопу. Скорость продвижения согласована с длиной
шага. Разная длина ног и ботинок учитывается при выборе высоты таза.

Все компоненты текущей позы непрерывно идут к новой цели через одну
критически затухающую пружину с сохранением текущей скорости. Углы идут
по кратчайшему пути. Подготовка, полёт и приземление меняют только цель;
таблицы отдельных переходов между парами состояний нет. Физика и смешивание
считаются подшагами не более 1/120 секунды, показ зависит от кадров браузера.
Прыжок запускается по земле; повторный прыжок в воздухе не буферизуется.

`tests/motion.test.js` проверяет фазы и возврат после прыжка, произвольные
переключения, непрерывность смешивания, кинематику и сценарий двух прыжков.
Это проверки поведения, а не доказательство качества иллюстрации: стыки и
силуэт дополнительно смотрят в настоящем браузере.

## Границы PoC

Один персонаж и заранее известный скелет. Это ручное задание суставов и
процедурных движений агентами, а не автоматическое оживление произвольного
изображения. Кисти включены в предплечья, волосы и шарф — в голову/туловище.
Резкий разворот зеркалит персонажа сразу; отдельной анимации поворота нет.
Стопы при ускорении и переходах могут слегка скользить: пружина обеспечивает
непрерывность, но не является полноценным решателем контакта с землёй.
Точная естественность движения — предмет визуальной оценки, а не итог
автоматического теста.
