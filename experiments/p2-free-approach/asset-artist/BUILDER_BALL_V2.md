# Готовый шарик для малого примера Builder

Текущий manifest: `asset-contract-v2.json`, статус
`READY_ASSET_RUNTIME_UNVERIFIED`. Все `file` заданы относительно этого manifest.

| Поле | Значение |
| --- | --- |
| `ball.file` | `ball-v2.png` |
| `ball.centerPx` | `[627,629.5]` |
| `ball.diameterPx` | `830.5` |
| `ball.canvasPx` | `[1254,1254]` |
| sizing bounds при alpha >=128 | `[211,215,1043,1044]`, right/bottom exclusive |
| все ненулевые alpha bounds | `[79,87,1200,1148]`, right/bottom exclusive |
| SHA-256 | `3484ec77027226f061bce2738972aed404455bb15c8c778fe5a3de6c7ffecfc3` |
| размер файла | `851662 bytes` |

Для принятого физического r16 и H, `w=H20*x+H21*y+H22`:
`spriteScale=(2*16/w)/830.5`, одинаково для обеих осей. Видимый диаметр —
`2*16/w`; полный canvas имеет размер `1254*spriteScale`.
Anchor полного canvas — `[0.5,0.501993620414673]`, измеренный центр сферы.
Не задавать width полного canvas равным диаметру шарика: прозрачный padding
сделает шарик слишком маленьким. `liftRadii` не задан: остаётся согласованная
локальная оценка высоты из H, без изменения физического состояния.

Прозрачный край canvas проверен. В padding есть остаточные точки alpha 1/255;
внутренний диск на 80% радиуса имеет alpha не ниже 252/255. Полной непрозрачности
каждого внутреннего пикселя не заявляю. Нет baked cast shadow. Исходный и
исправленный PNG не редактировались другим инструментом; выбранный файл
побайтно совпадает со вторым raw imagegen. Метрики — `ball-v2.metrics.json`.

Тень прежняя, отдельная: `shadow-native-disc-v1.png`, 128 × 128, центр `[64,64]`,
texture radius48, native radius18.4, native offset `[-8,+14]`, alpha0..76.
SHA-256 `bd54c9f8251b634657076831fd38854855aea8004ea4dc71603b3bac3a39f572`.
Проецировать как элемент пола; source-тени препятствий повторно не добавлять.
Свет шарика сверху справа и это направление тени согласованы при статическом
сравнении с Jungle. Плотность, grounding и перекрытия в runtime не проверены.

Четыре пробных контура остаются в `occluders-v1.json`. Другие контуры и корзины
не расширялись. Диагностика остаётся вне художественных масок.
Включение в реальный движущийся пример и независимая QA ещё не выполнены.
