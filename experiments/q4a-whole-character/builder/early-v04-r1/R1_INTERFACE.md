# R1 — интерфейс source geometry до прогонов

25 октября 2026. Builder `builder-r4d-q4a-01`. Старт R1 получен после pushed R0 `746cd6d27ef386642ad50261d6d611398db67a57`. Старые R0/source/guide не меняются. Этот файл сообщает художникам конкретные новые ориентиры/материальный интерфейс для согласованного минимального теста; не объявляет отсутствующие материалы готовыми.

## Анатомические центры v04 для сверки

Сохраняю уже совместно принятые source-оценки ног: pelvis(505,730); near hip(465,725), knee(416,979), ankle(274,1370); far hip(550,735), knee(670,972), ankle(699,1375). Near — к левой на экране обуви. После повторного чтения raw не вижу основания переносить центры к серединам PNG. Это внутренние суставные ориентиры по объёму тела, не обязательные видимые пиксели под тканью. Shoulder swing pivot предлагаю внутри округлой ближней дельты **(434,330)**; реальный elbow около(617,500), wrist около(827,582). Минимальный тест вращает всю исходную arm-chain целиком вокруг shoulder±25°, без отдельного сгиба локтя/кисти; их расстояния/форма сохраняются.

Прошу Asset/Concept сверить именно эти центры до фиксации GEOMETRY: плечо не переносится к пройме/переднему краю руки, hip не назначается в центре штанин. Существенное анатомическое расхождение фиксируем до прогонов. Drop230/back110, длины и один cage-способ неизменны.

## Material interface Asset → Builder

Предпочтителен один `MATERIALS.json` в зоне Asset: native source1024×1536, у каждого PNG `id`, `file`, `cropRect:[x,y,w,h]` (либо full-canvas), `owner`, `source-extracted/reconstructed` и provenance/visible-hidden distinction. Цветовой фон alpha0 не материал. Сами pixels/мasks только Asset; Builder их не переизготавливает.

Минимально достаточно: torso/head/tank с согласованным локальным hidden восстановлением; far arm, сохраняющий исходный вид; near arm-chain только кожа с проксимальным hidden продолжением при доказанной нужде; по двум ногам thigh/shin/shoe, необходимые внутренние продолжения только там, где раскрываются; одна непрерывная hip/shorts texture плюс source trace контура и waistband/two leg openings/side-crotch seams. Набор нужен только для shoulder/hip test, не full animation kit. Можно передать эквивалентный manifest без смены смысла.

Для cage нужны **actual source** boundary и наблюдаемые швы: верхняя pelvis boundary, два leg-opening paths, наружная ягодичная дуга, шаговая связь; owner каждого края и occluded участки названы отдельно. Нижняя кожа должна соответствовать собственному thigh; hidden overlap минимален и отмечен. Не делить shorts на альтернативные rigid panels, не приносить v02 geometry/anchors или donor skin от другого whole.

## Неподвижные технические условия

Rest geometry/topology, один rest-shape solve и boundary constraints сохраняются до первого прогона. Верх cage следует pelvis, каждый cuff — rigid transform своего thigh; внутренние вершины решаются одним общим методом с orientation/distortion контролем, без кадровых поправок. Фиксируем даже отрицательный результат; cuffs/low не замораживаются ради positivity.

Реальная dense alpha-support каждой обуви вычисляется по материалу Asset. Целевой floor задаётся общим; позиция ankle определяется rigid shoe contour относительно ankle, а позиция knee — всей IK chain с исходными постоянными длинами. Shoe не имеет отдельного корректирующего offset/scale. Source alpha1 noise показываем отдельно. Low=root(-110,+230) от выровненного neutral при постоянных стопах/длинах; shoulder±25° относительно source. Torso пока переносится с pelvis без дополнительного неподтверждённого наклона, чтобы не ввести второй waist solve.

Технический endpoint/URL будет один с исходным whole рядом и light/dark. До готового exact after общего PASS нет. Сейчас согласование интерфейса; отсутствие частей/repair не замещается заглушками. Frozen R0/source/guide и старые snapshots не трогаются.
