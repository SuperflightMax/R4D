## Что получилось

Запускаемая PixiJS-демонстрация собирает художественного профильного
персонажа из 14 активных прозрачных PNG на иерархическом риге. Есть стойка,
зацикленное движение, подготовка/полёт/посадка прыжка, живые старты,
остановки и прыжки из стойки и движения. Любая смена состояния захватывает
текущую показанную позу и одним механизмом смешивает её с новой динамической
целью; таблицы отдельных переходов нет.

Диагностика показывает состояние, фазу, запрос, ход смешивания и кости;
поддерживаются пауза и автоматическое воспроизведение сценариев. Production
`dist/` самодостаточен.

## Запуск и проверка

```powershell
cd D:\dev\R4D\experiments\gpt-5.6-sol
npm ci

npm run preview
```

Управление: `A/D` или стрелки — движение, `Space` — прыжок, `P` — пауза,
`B` — кости, `T` — автопереходы, `R` — сброс.

## Остаточные ограничения

Приняты ограничения из `QA_REPORT.md`: заметные тканевые коленные швы,
небольшое скольжение ботинка без IK, местное слияние дальних конечностей и
плотность диагностических линий в торсе. Они не мешают демонстрации
обязательных состояний, реальной нарезки, скелета и живого смешивания.
