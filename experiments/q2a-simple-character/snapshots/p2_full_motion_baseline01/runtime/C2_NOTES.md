# P1-C2: только колено

25 октября 2026. C1/C1_wrist сохранены отдельно. Таз, корни бедра/плеча,
голенище, motion и уточнённая привязка кистей сохранены из C1_wrist.

Личный просмотр Concept установил ухудшение внутреннего подколенного контура
в C1. Численная выборка610 непрозрачных точек исходной ближней ноги вокруг
колена: C1 на50/75/100% имеет minJacobian0,409/0,262/0,141, без отрицательных
значений в выборке. Сильное сжатие не равно хорошей форме; отсутствие переворота
не подтверждает художественный результат. На той же выборке initial имеет
2/16/23 отрицательных локальных производных: его схема тоже не идеальна.

Проверены две гипотезы: увеличить внутреннюю полуширину46→78px;
затем заменить вращательное смешивание линейным. Первый вариант увеличил
внутреннюю выемку, второй дополнительно потерял массу. Они отвергнуты;
кадры сохранены `output/playwright/c2-knee-*.png` и `c2-knee-linear-*.png`.

По прямому разрешению Lead восстановлена только лучшая исходная коленная
схема с зоной±28px; C1-соединение корня ноги с тазом сохранено. Это адресный
возврат после двух неудачных гипотез, не объявление колена решённым. Остаточная
складка/округлая масса и локальные проблемы схемы остаются предметом просмотра.
Low160px, длины костей, опора и PNG не менялись.

После фиксации этой версии новые руки подключаются отдельным шагом. Пределы
P1 сохраняются; художественный/QA PASS не выдан.
