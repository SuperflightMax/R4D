# Q2A: первый срез

Текущий объём — только idle ↔ выраженный low, без walk/jump, независимого QA и публикации.

Из `D:\dev\R4D\experiments\q2a-simple-character`:

```powershell
npm start
```

Открыть http://127.0.0.1:4322/runtime/. Сервер привязан только к localhost.
Нужен Node.js. PixiJS 8.22.0 сохранён в `runtime/vendor/` с лицензией;
для показа установка npm-пакетов и внешняя сеть не нужны. `npm ci` нужен
только для восстановления исходной npm-зависимости при разработке.
Кнопки меняют цель во время перехода; пауза останавливает также дыхание.
Ползунок выбирает промежуточную позу. Доступны светлый/тёмный фон и ориентиры.

До фактической передачи нового комплекта показывается только техническая настройка,
которая не является растровым результатом или художественным PASS.
Asset владеет `art/`; Builder не изменяет исходники и метаданные Asset.
`runtime/art-binding.json` фиксирует фактическую передачу attempt03_initial.

Первая диагностическая растровая сборка сохранена неизменной в
`snapshots/attempt03_initial/`. Её отдельный сервер — http://127.0.0.1:4323/runtime/.
Из каталога снимка: `$env:Q2A_PORT='4323'; node runtime/server.mjs`.
Снимок содержит все зависимости, raw и metadata. Фактические пропорции
отличаются от первоначальной схемы; рост около702 вместо768. Это явно
обозначенный диагностический кандидат, художественная приёмка ожидается.
