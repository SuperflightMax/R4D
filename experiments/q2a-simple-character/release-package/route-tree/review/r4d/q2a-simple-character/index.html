Об опыте и ограничениях

Q2A принят CTO как завершённый PoC с ограничениями. Два независимых QA получили PASS в проверенном объёме. Это не художественное совершенство и не доказательство универсальности метода.

Остаются резкий сгиб колена, линия шорт, жёсткость плеча и ограниченная видимость дальней стороны. В воспроизведённых переходах отмечены сильные сгибы стопы: 49,20° при носочной опоре и 61,26° у свободной стопы; условия контакта различаются. Есть субпиксельное пересечение свободной стопы с землёй.

Проверки выполнены агентами в браузере; реальный телефон/touch, каждый момент команды и все кадры не проверены.
