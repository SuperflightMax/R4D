## Обязательное поведение

- Полный исходный кадр и полный рабочий кадр в одном масштабе. В desktop1920×1080 картина помещается целиком с сохранением пропорций; техническое управление вынесено за её пределы. Исходные пиксели доступны для увеличения/проверки краёв.
- После ревью первого каркаса CTO зафиксировал показ: по умолчанию одно крупное рабочее полотно, вписанное целиком в доступный desktop1920×1080; исходник переключается в том же окне и масштабе без сброса прогона. Постоянная пара уменьшенных колонок заменяется этим показом. Режим1:1 остаётся доступен, управление/подпись вне картины. Это способ показать принятый master и те же состояния, без расширения игрового объёма.
- Реальные клики по видимым контурам хлеба и миски с тестом; клик по соседнему льну, дереву, морю или пустому углу прямоугольника предмета ничего не подбирает. Удалённое больше не кликается.
- Четыре состояния: оба; без хлеба; без миски; без обоих. Два порядка дают одинаковый окончательный рисунок и состояние. После любого другого действия внутри прогона снятое не возвращается; отдельный явный сброс начинает новый прогон.
- Короткий переход около0,2с: предмет и только его фактическая зависимая тень исчезают согласованно; неподвижные края не плывут. Не маскировать дефекты изменением всей сцены.
- Сравнение исходник/рабочий и сброс управляются понятными кнопками вне арта. Для QA сохраняется возможность получить начало/середину/конец перехода и воспроизводимые последовательности кликов.
- Внешняя часть ROI сохраняет exact исходные пиксели. Изменения внутри — только проверенные художественные производные. Если используются готовые состояния, честно указать предел: доказаны ровно два объекта, масштабирование не доказано.
