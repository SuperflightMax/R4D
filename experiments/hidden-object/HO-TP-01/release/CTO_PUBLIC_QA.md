## Реальный браузер

Анонимный переход не перенаправлялся на вход. Четыре необходимых браузерных запроса получили 200; ошибок выполнения приложения и failed requests — 0. В readonly checkpoint сохранён PARTIAL. Видимая русская оговорка: у миски остаётся шов на стыке со льном, художественная приёмка ещё впереди.

Проверены хлеб→миска, явный reset, миска→хлеб. Каждый клик выполнялся по реальному измеренному Canvas и нативным предметным координатам. Reset вернул исходный кадр. Оба порядка дали одинаковый конечный RGBA SHA-256 **`0f898f2049504c426f8776e392938dcbe3d973e0b396050eafba25d330502f7a`**, совпадающий с принятым локальным измерением после одинакового readonly readback warmup. Исходный RGBA — `d7cdb91db738d979593693e8960fecc8a4024c7006dd86b33fad0eaca60f140e`.

Обычный `/favicon.ico` на origin, вне четырёх файлов и версионного leaf, сообщил 404. Chromium отразил его в console, без Page response event. Наблюдение сохранено; оно не объявляется успешным запросом. Продукт и инфраструктура ради иконки не менялись. Условия PASS относятся к четырём необходимым ресурсам и управлению пилотом; чистая консоль без любых сообщений не заявляется.

## Измерительные уточнения и доказательства

Первый проход ошибочно требовал буквальное PARTIAL в видимом тексте, где используется русская оговорка; он не дошёл до кликов. Второй прошёл все предметные действия и совпадение кадров, но общий assert включил origin favicon404 в ошибки приложения. Исправлены только критерии измерителя: проверяются PARTIAL в данных и реальный русский текст, а ровно этот внешний favicon404 учитывается отдельно. Исходные квитанции сохранены, продуктовые байты не менялись. Итоговый повтор прошёл.

Финальная квитанция: `K:\Agents\R4D\Review\HO-TP-01\release\cto-public-v004-20261119T1737Z-v3\cto-public-check.json`, SHA-256 **`9bb8e86e68e13a4e30aa923a40545c637ac05520a1661d244c2158cbd57fc8a3`**. Там же actual initial/both-removed public desktop PNG; итоговый снимок лично осмотрен CTO, браузер закрыт. Две предыдущие квитанции — соседние папки без `-v3`; это диагностическая история, не дополнительная приёмка. [Проверочный сценарий](cto-public-check.cjs).
