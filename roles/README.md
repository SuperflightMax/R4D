# Проектные дополнения к ролям R4D

Редакция: **23 октября 2026 года**. Эти инструкции относятся к исследовательской работе R4D в любой предметной области. Общие профессии остаются в [каталоге Staff Department](https://github.com/SuperflightMax/codex-staff-department/blob/main/roles/README.md).

## Что получает сотрудник

1. [Playbook Макса](https://github.com/SuperflightMax/Chatknows/blob/main/PLAYBOOK.md); при отсутствии доступа — [публичный снимок](https://github.com/SuperflightMax/codex-staff-department/blob/main/PLAYBOOK.md).
2. Свою общую роль из Staff Department.
3. [Общие инструкции R4D](COMMON.md).
4. Дополнение своей роли из таблицы ниже.
5. Текущее поручение и только нужный ему контекст опыта: цель, границы, применимая специализация и материалы.

Общие инструкции и своё дополнение читает каждый участник. Остальные карточки нужны для выбора компетенции, а не для обязательного чтения всей командой. Предметная специализация, стек и настройки конкретного эксперимента живут в его поручении и материалах; они не переписывают профессию. Новая роль без отдельной карточки использует общую роль и `COMMON.md`; дополнительный файл появляется при содержательной необходимости.

## Как передавать через Staff Director

В запросе на создание или обновление сотрудника R4D CTO/Lead указывает ID общей роли, `roles/COMMON.md`, соответствующий `roles/<role-id>.md` и актуальное поручение. Достаточно версии репозитория, по которой выдаются инструкции; отдельная система версий карточек не нужна.

[Staff Director](https://github.com/SuperflightMax/codex-staff-department/blob/main/roles/staff-director.md) остаётся общей кадровой ролью. Эта карта даёт ему проектные источники для выдачи; отдельный исследовательский дубль его профессии не создаётся.

Публикация файлов не обновляет действующие сессии. **Пакет подготовлен для последующей передачи Staff Director по отдельному поручению Макса.** До фактической доставки не утверждаем, что сотрудники уже его получили. Обновление инструкций само по себе не перезапускает завершённые опыты и не запускает обсуждаемые исследования.
